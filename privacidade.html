Política de Privacidade

Última atualização: 9 de outubro de 2026

Esta política descreve como a Fábrica de Vídeos, ferramenta interna do canal Cão Danado Games (responsável: Robson Gonçales Founar, Diadema, São Paulo, Brasil), usa dados obtidos pelos Serviços de API do YouTube.

Quem usa

O aplicativo é de uso pessoal e interno. O único usuário é o dono do canal Cão Danado Games, que autoriza o acesso à própria conta do YouTube. Não há cadastro de outras pessoas.

Dados acessados

  • Envio e agendamento de vídeos, thumbnails e legendas no próprio canal (YouTube Data API).
  • Leitura de dados públicos de vídeos do YouTube (títulos, visualizações) para pesquisar temas em alta.
  • Estatísticas do próprio canal, como visualizações, horas assistidas e retenção (YouTube Analytics API).

Como os dados são usados e guardados

Os dados ficam somente no computador do dono do canal e são usados apenas para produzir, publicar e melhorar os vídeos do próprio canal. Nada é vendido, compartilhado com terceiros ou usado para publicidade. O token de acesso fica guardado localmente e pode ser apagado a qualquer momento.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os dados guardados localmente são apagados pelo próprio dono em até 7 dias.

Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Privacy Policy (English)

Fábrica de Vídeos is a private, internal-use tool of the Cão Danado Games YouTube channel (owner: Robson Gonçales Founar, Diadema, São Paulo, Brazil). Its only user is the channel owner, who authorizes access to his own YouTube account.

Data accessed: uploading and scheduling videos, thumbnails and captions on the owner's own channel (YouTube Data API); reading public YouTube video data (titles, view counts) for topic research; reading the owner's own channel analytics such as views, watch time and retention (YouTube Analytics API).

Use and storage: data is stored only on the owner's computer and used only to produce, publish and improve the channel's own videos. Nothing is sold, shared with third parties or used for advertising. The access token is stored locally and can be deleted at any time.

Revoking access: access can be revoked at any time at myaccount.google.com/permissions; locally stored data is then deleted by the owner within 7 days.

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
